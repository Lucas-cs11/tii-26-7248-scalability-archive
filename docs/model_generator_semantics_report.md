# v6 model-generator semantics report

All 12 declared families pass exact representative semantic validation at the
predeclared seed 0. Each family has a time-feasible normal completion and a
fault-containing completion. Families declaring optional inspection or rework
also have a complete execution containing that branch. WIP concurrency is
demonstrated by simultaneous release traces up to the declared capacity.

The validator checks workpiece conservation, the WIP semaphore invariant, and
each machine-capacity invariant from the transition incidence relation. New
route-choice transitions are verified unobservable.

Immediate route choices do not directly consume observable-word length `L`.
Selecting inspection contributes its single declared inspection observation.
Selecting rework contributes the declared rework observation plus the
observations generated by repeating the operation. Therefore v5 `L` values are
not silently assumed equivalent: v6 Pilot and formal manifests derive and
freeze their `L` grids from corrected model structure before execution.

Machine-readable per-family sequences, exact event times, hashes, network
sizes, invariants, and applicability are generated under
`family_semantic_witnesses/` by `scripts/validate_v6_model_semantics.py`.
